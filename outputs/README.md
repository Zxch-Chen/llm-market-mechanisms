# Experiment data

These files are committed research artifacts. Analysis reads them without credentials. New runs default to ignored `outputs/local/` directories.

The v1 conditions are two mechanisms × two prompts. The v2 conditions are two mechanisms × three framings. A v2 call row includes its retry when present, so row counts differ from provider request counts.

Each v2 batch has `summary.jsonl`, `results.md`, and `runs/<run_id>/{calls,events}.jsonl`. See the [v2 guide](../v2/README.md) for fields and the [v1 schema](../docs/schema.md) for original logs.

`v2/tinker/discarded_cancel_before_accept_bug/` contains six failed negotiation pilots. They do not contribute to summaries or published analyses. We retain them to document the cancellation-order bug fixed before the main run.

The model prompts use fictional client names and scenarios generated by `v2/economy.py`. Read the [reproducibility notes](../docs/reproducibility.md) for limitations and the post-experiment parser fix.
